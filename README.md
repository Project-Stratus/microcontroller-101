# Microcontroller 101
Quick intro to microcontrollers using the Arduino Nano Every. No prior electronics experience needed. The sketches should work on other Arduino boards, but pin numbers may need changing.

## Setup
1. Install Arduino IDE 2.3.10 - [Link to installation](https://www.arduino.cc/en/software/)
2. Open Arduino IDE. In Boards Manager (Found in left hand side column), install **Arduino megaAVR Boards (1.8.8)**

## Materials
* Arduino Nano Every
* Micro-USB data cable
* Breadboard
* LED
* Resistor (~200 ohms)
* Push Button
* Potentiometer (10k ohms)
* Wires
